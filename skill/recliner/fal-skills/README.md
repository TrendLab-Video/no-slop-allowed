# Bundled fal skills

These are verbatim copies of fal's agent skills. They are a backup for sessions where the skills are not installed. If a skill is installed, use the installed one; see the "fal skills" section of `../SKILL.md`.

- **Source:** https://github.com/fal-ai-community/skills (the `skills/` folder). This is fal's public skills repository; their docs for the agent skills are at https://fal.ai/docs/documentation/agent/skills.
