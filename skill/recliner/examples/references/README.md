# Example reference set

A shape guide for `steps/references.md`: how deep a good `references.json` entry goes. The entries are **illustrative**: titles, URLs (example.com) and figures are made up to show the shape and the kind of disparity wanted. A real run must find real, current posts and cite where each metric came from. Never copy these picks into a run.

What makes these entries good:
- Every entry differs from the others on format, hook and music (macro product, creator POV, kinetic type, mockumentary).
- `structure.scenes` is timed, so the goals stage can borrow a rhythm, not just a vibe.
- `hook` names the exact first-second mechanic.
- `why` says what transfers and names the source of the figures.
- `takeaways` name their reference ids; `diversityNote` says which obvious picks were excluded.
